# Trail Quest

A tiny command-line adventure game written in Python 3 using only the standard
library. Pick between two outdoor paths, make one more choice, and reach one of
three endings.

Built for the MLH Global Hack Week "Build a Mini App with Cursor" challenge.

> **Disclosure:** The code in this repository was generated by Cursor's AI agent.

## Requirements

- Python 3.8 or newer
- No third-party packages, network access, or API keys

## Run

```sh
python3 trail_quest.py
```

At each prompt, type `1` or `2` and press Enter. Invalid input re-prompts.
Press Ctrl+D (Ctrl+Z then Enter on Windows) to quit early.

## Endings

| Choices | Route | Ending |
| ------- | ----- | ------ |
| `1`, `1` | Forest Path, follow the markers | Summit |
| `1`, `2` | Forest Path, take the shortcut | Lost |
| `2`, `1` | River Path, follow the riverbank | Lake |
| `2`, `2` | River Path, hop across the stones | Lost |

## Scripted play

You can pipe choices in to play without typing:

```sh
printf '1\n1\n' | python3 trail_quest.py   # Summit ending
printf '1\n2\n' | python3 trail_quest.py   # Lost ending
printf '2\n1\n' | python3 trail_quest.py   # Lake ending
```
